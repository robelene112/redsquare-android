# Red Square Android

A planned native Kotlin Android client for Saito's Red Square, with a familiar
social experience, responsive interaction and a non-custodial wallet.

This repository currently contains project context and development workflow
setup. Android application code, build tooling and APK delivery are not yet
implemented. The first-release feature list remains to be grilled.
