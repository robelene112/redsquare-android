# Independent funded-payment first cycle

The retained fixture was generated by payment-reference.cjs in a network-disabled,
read-only, no-new-privileges/capability-dropped container with only named read-only
WASM/dependency/runtime/reference-code mounts and an empty process environment.
Pinned Node24.13.0, WASM0.3.2 and Elliptic6.6.1; binary identity is in the fixture.
Only pure slip/transaction serializers, hashing and signature functions execute.
The generator agrees with the previously documented literal signature/hash and
independently verifies through Elliptic and WASM. It does not initialize Saito.

One native core case first compiles and fails at the explicitly unimplemented
funded constructor (UnsupportedOperationException,47s build), then passes after
minimal funded construction (47s build). Expected signed signature, all621 wire
bytes, detached envelope and752-byte routed frame are independent literals.
Public unsafe scalars1/2/3 and synthetic UTXO coordinates must never hold funds.
This proves serialization/signature compatibility, not consensus admission,
real UTXO ownership/eligibility, inclusion or an authenticated Android transfer.
Funded restoration, reservations and native transfer behavior remain unfinished.
