## Behavior

The native Talk module creates and joins rooms, previews compatible links and
supports three-party media, participant entry/leave, local preview, microphone,
camera, camera switch and audio output. A private conversation's phone button
opens Audio call/Video call choices without adding another header row. Active
calls have Android return/hang-up controls; voice continues in background and
with the screen off, while camera pauses outside visibility. An invitation starts
no capture. Process death interrupts rather than silently restoring a call.

The selected wallet/node, unsent drafts, module/conversation destination, Chat
and Fileshare keep their ownership. A completed or saved file releases streaming
and foreground work while a visible conversation retains its shared connection.
Exact transfer tokens govern final cleanup. Repeated final chunks acknowledge
without reopening a spool or downgrading Saved. No recording, transcription,
scheduling, livestreaming or local screen broadcasting is added.

browser's first submitted description to be an answer, covering native initiation.

as full upstream Stun execution at that older seam.
